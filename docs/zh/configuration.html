配置

用 YAML 组合项目

Suzumio 配置既可以作为单文件阅读，也可以拆分维护。用 whole-field import 引入任务和 prompt，用 extends 组合可复用 profile。

最小项目

name: demo
task: |
  Demonstrate one non-preemptive turn.

backend:
  runner:
    mode: mock

agents:
  pm:
    role: project-manager
    prompt: |
      Handle the user request and stay concise.
    tools:
      - messages.send

主要字段

字段是否必需默认值说明
name是无项目 id 和运行目录名。
task是无持久任务描述，会渲染进每个 turn prompt。
agents是无至少配置一个 agent。
scheduler否nonpreemptive-mailbox调度器类型和 prompt message 数量。
backend否Docker + mock runnerDocker image、controller URL 和 runner 设置。
channels否#project, #blocked允许的频道名。

Whole-field Import

当某个字段的整个值是 @import(path) 时，该字段会被导入文件替换。这不是字符串插值。

task: @import(tasks/main.md)
agents:
  pm: @import(agents/pm.yaml)
文件类型行为
.yaml 或 .yml作为 YAML 解析并递归 resolve。
.json作为 JSON 解析并递归 resolve。
其他扩展名作为原始文本导入。

Import 路径相对当前文件解析。禁用 HTTP import，并检测循环 import。

Extends

extends 用于 profile composition。Suzumio 先 deep-merge extends 中的对象，再把当前文件 merge 到最上层。

extends:
  - @import(profiles/base.yaml)
  - @import(profiles/acorn.yaml)

name: theorem-project
task: @import(tasks/theorem.md)

Merge 规则：object 深合并，array 替换，后面的值覆盖前面的值。

Backend 和 AI Runner

backend:
  kind: docker-chat
  image: suzumio-runner:dev
  controllerUrl: http://host.docker.internal:39400
  runner:
    mode: ai
    model: main
    models:
      default: main
      providers:
        gateway:
          type: openai-compatible
          baseURL: https://your-gateway.example/v1
          apiKeyEnv: SUZUMIO_GATEWAY_API_KEY
      presets:
        main:
          provider: gateway
          model: gpt-5.5
          apiModel: gpt-5.5

提交到仓库的示例必须保持脱敏。真实 endpoint 和 key 应放在本地未跟踪配置或环境变量中。

Agent 和 Channels

agents:
  worker:
    role: worker
    count: 2
    prompt: @import(prompts/worker.md)
    model: main
    tools:
      - messages.send
      - artifacts.publish
      - artifacts.list

channels:
  - "#project"
  - "#blocked"

count 会展开为多个编号 agent。频道消息只能发送到已声明 channel，避免拼写错误制造噪音。

验证流程

suzumio config render path/to/project.yaml
suzumio init path/to/project.yaml
suzumio status project-name

config render 是查看最终导入、默认值和存储内容的标准方式。
