Quickstart

Run a Docker-backed mock turn

The mock demo verifies the core runtime without needing an API key: config loading, SQLite state, HTTP server, scheduler, Docker runner, and turn completion.

Prerequisites

  • Node.js 24 or newer.
  • Docker available to the current shell.
  • Git if you want to commit local changes.

Install and Build

git clone git@github.com:OmegaCombinator/suzumio.git
cd suzumio
npm install
npm run build
docker build -t suzumio-runner:dev .

Create a Runtime Root

Keep runtime state outside the repository. This prevents SQLite databases, turn files, and agent workspaces from mixing with source files.

export SUZUMIO_ROOT=/tmp/suzumio-root
mkdir -p "$SUZUMIO_ROOT"

Initialize a Project

suzumio init examples/demo.yaml
suzumio status demo

The project directory will contain suzumio.sqlite, the source config, the resolved config, agent workspaces, artifacts, turns, and logs.

Start the HTTP Server

suzumio serve --host 0.0.0.0 --port 39400

Open http://127.0.0.1:39400 for the WebUI. The server also runs the scheduler loop by default.

Start the Project and Send Work

In another terminal with the same SUZUMIO_ROOT:

suzumio start demo
suzumio send demo pm P1 "Start the mock demo and report status."

Inspect the Result

suzumio turns demo
suzumio messages demo
suzumio events demo

A successful mock run should show one completed turn for pm. The completed turn text is written by the isolated container runner.

AI Runner Smoke Test

The committed AI example is sanitized. It uses an environment variable and a placeholder gateway URL. Do not commit real base URLs or keys.

export SUZUMIO_GATEWAY_API_KEY=...
suzumio init examples/ai-demo.yaml
suzumio serve --host 0.0.0.0 --port 39400
suzumio start ai-demo
suzumio send ai-demo pm P1 "Send one status update to the user."

Use local untracked config for real provider endpoints. The repository examples must stay sanitized.

Common Problems

SymptomLikely CauseFix
Docker build tries to pull a base image and times out.The local Docker cache does not have the base image.Use an available local Node image or configure your registry mirror.
Turn fails with connection refused on tool calls.The container cannot reach Suzumio HTTP server.Start suzumio serve --host 0.0.0.0 and keep controllerUrl: http://host.docker.internal:39400.
Agent stays quiet.It has no unread inbound messages.Send a direct message to the agent or to a channel it can read.
